# Lilja (@kamahir0-lilja)

Independent Unity libraries and tools developed by [@kamahir0](https://github.com/kamahir0).

---

## 📌 概要と設計思想

**Lilja** は、Unity向けの独立した軽量ライブラリ・ツール群のブランドです。

- **完全独立**: 各パッケージは他のLiljaパッケージへの依存を持たず、個別に導入・開発・リリースされます。
- **Embedded Package構成**: 各リポジトリ自体が独立したUnityプロジェクトとして機能し、Unity Hubから直接開いて開発・動作検証が可能です。
- **技術実験の分離**: 技術検証、PoC、学習用のプロジェクトは [**kamahir0-playground**](https://github.com/kamahir0-playground) にて管理しています。
